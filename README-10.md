## Core idea

This repository contains the candidate **Autonomous Evolutionary Vector (AEV)** model for NOVA Q / EIT.

`nu_AEV* = (N_novel × C_coh × V_valid) / (Delta_t × (1 + R_red))`

The framework explicitly separates:

- novelty from validity,
- generation from validation,
- provenance from truth,
